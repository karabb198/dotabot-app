# Дота-помощник — мини-приложение

Мини-приложение Telegram-бота [@Dota2YourTracker_bot](https://t.me/Dota2YourTracker_bot):
удобный выбор пика и сборки, мини-игры «Найди контрпик» и «Что собрать против».

Открывается из бота кнопкой «🎮 Приложение». Данные о контрпиках — таблица dota2.ru,
герои и предметы — OpenDota. Dota 2 и все связанные материалы принадлежат Valve.
